# Provenance

Kobento is an implementation of the **RemoteCompose** spec (Android/androidx). Several pieces
here are, for now, bundled prebuilt or vendored from upstream sources. This file records where
they came from. As each is rebuilt on Kobento's own code, the entry is updated and the build
repointed to the new library.

## Engine — `components/rccore` → the future `kobento-cpp`

The RemoteCompose core engine is built in place from the sibling checkout
`../remotecompose-experiments` (`players/cpp/lib/rccore`), via `components/rccore/CMakeLists.txt`.
That tree is the C++ RemoteCompose reference implementation and is owned upstream. It will be
rebranded and split out as **kobento-cpp**; when that lands, `components/rccore` repoints to it.
Not modified from this repository.

## Renderer — `third_party/thorvg` (branded **KobentoVG**)

A fork of **ThorVG** (MIT), vendored at v1.0.7, with local patches:

- a text-metrics bug fix (space poisoning the font), and
- the RcVG work (sweep/conic gradient, text-on-path, 2D meshes, backend fixes — see
  `docs/RCVG_STUDY.md`).

The integration layer we author on top of it — `components/kobentovg` (`ThorvgPaintContext`,
namespace `kobentovg`) — is **KobentoVG**, Kobento's vector-graphics layer. It has nothing to
do with RemoteCompose and does not carry the `rc` prefix. Upstream ThorVG:
<https://github.com/thorvg/thorvg>.

## Documents — `documents/*.rc`

Prebuilt RemoteCompose documents, embedded by both targets. Origins:

- The demo documents are traced from or derived from **RemoteCompose-Examples**
  (<https://github.com/hoford/RemoteCompose-Examples>) and the androidx RemoteCompose demos.
- `kobento_splash.rc` (the start-up screen) is drawn from scratch by `tools/splash/make_splash.py`
  — the Kobento bento-box mark and wordmark, no third-party artwork.
- They are compiled to `.rc` with `json2rc.js`, vendored from RemoteCompose-Examples under
  `tools/splash/`.

These are bundled as prebuilts today; they will be regenerated by Kobento tooling and this note
updated accordingly.

## Fonts — `assets/fonts`
